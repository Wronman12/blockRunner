# Sunny Wheels

Sunny Wheels is a bright and friendly endless bike racing game created for young riders. Slide between three smooth lanes, collect sunshine tokens, and dodge bouncy puddles while the game gently speeds up. The controls are simple enough for early-primary kids in 2025: tap the big arrows on mobile or press the left and right arrow keys on desktop.

## Play the game

Open `index.html` in any modern browser. The layout adapts to phones and tablets automatically—no extra build step required.

## Controls

- **Desktop:** `←` and `→` keys (or `A` and `D`) move the bike between lanes.
- **Mobile:** Tap the large on-screen arrow buttons.
- **Bonus:** Press `Enter` or `Space` to start a fresh ride from the keyboard.

## Features kids enjoy

- Cheerful, high-contrast visuals with soft animations designed to be easy on young eyes.
- Gentle difficulty curve that keeps the track exciting without overwhelming new players.
- Automatic pausing whenever the game tab loses focus, helping families manage interruptions.
- Local best-score tracking so riders can celebrate personal wins without online accounts.

Have fun racing!
